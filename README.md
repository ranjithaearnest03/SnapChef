🍎 SnapChef

AI-Powered Food and Product Detection

SnapChef is an AI-powered application designed to detect and identify food items and everyday products using image recognition technology.

🚀 Features

- AI-powered object detection
- Image-based product identification
- YOLOv8-based detection
- In-browser AI inference
- User-friendly interface

🛠️ Technologies Used

- React
- TypeScript
- Vite
- YOLOv8
- ONNX Runtime Web

🎯 Project Goal

To make product and food identification easier through artificial intelligence and computer vision.

🔮 Future Improvements

- Improved detection accuracy
- Food product authenticity verification
- AI-based fake product detection
- Expanded product database
